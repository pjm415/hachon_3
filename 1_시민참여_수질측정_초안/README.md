# 🌊 1. 시민이 직접 참여하는 수질 측정 (초안)

본 프로젝트는 **임하천 수질 정화 및 비리 방지**를 위해 **"시민이 직접 참여하는 수질 측정 & 동백전 리워드 시스템"**을 구현한 앱 프로토타입 초안입니다.

---

### 📌 주요 구성 및 핵심 기획

1. **데이터 위·변조 방지 수질 측정**:
   - 갤러리 선택 금지 ➔ 실시간 카메라 전용 (GPS 좌표 및 타임스탬프 영구 암호화).
   - 산책로 무인 자판기 1회용 키트 바코드 또는 카페 대여 다회용 센서 QR 스캔 연동.
   - 측정 완료 시 **부산시 동백전 +1,000원 캐시백 적립**.

2. **이태엽과 함께하는 줍깅 챌린지 (ESG 행사의 장)**:
   - 매월 정기 플로깅 이벤트 참가 신청 및 쓰레기 수거 인증.
   - **'8월의 수호자' 배지 + 동백전 3,000원 추가 리워드**.

3. **우리동네 하천살리기 지정 업소 (골목 상권 상생)**:
   - 하천 주변 제휴 카페에서 다회용 센서 무료 대여.
   - 기기 반납 시 **아메리카노 1,000원 할인 쿠폰 즉시 발급**.

---

### 📂 프로젝트 주요 파일

- **`standalone_app.html`**: 단일 HTML 문서로 빌드된 완성형 웹 앱 (더블 클릭으로 브라우저에서 즉시 실행 가능).
- **`clean_imha_app_presentation.md`**: 서비스 개요 및 미니멀 UI 디자인 설명 문서.
- **`src/`**: React + Vite 프론트엔드 전체 소스코드.

---

### 🚀 실행 방법

- 단일 HTML로 바로 보기: `standalone_app.html` 파일을 브라우저에서 열기
- 개발 서버 실행: `npm install` ➔ `npm run dev`
